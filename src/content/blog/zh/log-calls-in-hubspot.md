WaveKat Voice 现在可以把通话自动记录到 HubSpot。在你的 WaveKat 账户里连接一次 HubSpot，之后你接听或拨出的每一通电话都会自动写进你的 CRM——落在正确的联系人名下，带着时间、方向、结果、时长、转写全文，还有一段不用离开 HubSpot 就能播放的录音。不需要 API 密钥，不需要中间件，不需要浏览器插件，挂断之后也没有任何要记得去做的事。它今天已在[你的 WaveKat 账户](https://platform.wavekat.com/integrations)上线，是一项 Pro 功能——而在抢先体验期间，Pro 是免费的。

这仍然是我们在做的那件事的又一块拼图：[让每一家小企业都拥有大企业的声音](/zh/blog/hello-world/)。大公司的 CRM 之所以记得每一通电话，是因为有人专门负责让它记得。你的 CRM 也可以记得每一通电话——因为你本来就在用的那款[为每通电话录音并转写](/zh/voice/)的电话应用，会安静地把它写到你的客户资料所在的地方。

## 每通电话结束后，HubSpot 里会有什么

通话结束时，WaveKat 会按电话号码在你的 HubSpot 联系人里查找对方，并把一条通话记录写到对方的时间线上：

| HubSpot 里的内容 | 具体是什么 |
|---|---|
| 联系人 | 按电话号码匹配；没有匹配时可以自动创建 |
| 时间与方向 | 通话发生的时间，呼入还是呼出 |
| 结果与时长 | 已接听、未接或失败——以及通话持续了多久 |
| 标题 | 一行摘要，例如「呼入 · 已接听 · 非营业时间」 |
| 转写 | 完整的对话内容，除非你关闭转写同步 |
| 录音 | 通话有录音时，可直接在 HubSpot 自带的播放器里播放 |
| 链接 | 指回 WaveKat 里的这通电话，那里有波形图和流程的每一步 |

这条记录看起来就像一位尽职的同事手动登记的通话——只不过它覆盖每一通电话、逐字逐句，而且是在你去倒咖啡的时候完成的。同一个人打来两次，或者一次同步发生重试，同一通电话也绝不会被记两遍：WaveKat 记得哪条 HubSpot 记录属于哪通电话，会去更新它，而不是再造一条孪生记录。

## 在 HubSpot 里直接播放录音

录音并不会被复制进 HubSpot——实际发生的事更好。通话记录里带着 HubSpot 所需的信息，让它在*有人按下播放的那一刻*来向 WaveKat 询问音频，WaveKat 当场应答。这在实际使用中意味着：

- **播放就发生在联系人时间线上。** 同事在 HubSpot 里复盘一笔交易时按下播放就能听到通话——不用切换应用，不用转发文件。
- **删除一通电话，就是真的删除。** 录音在 WaveKat 里被删除后，HubSpot 那边没有任何残留副本可以比它活得更久。下一次按播放什么也找不到，因为确实什么也没有了。
- **访问权始终在你手里。** 每一次播放都是一次由 WaveKat 应答的请求，也就可以被拒绝——比如集成已断开、通话已删除。一份被复制走的音频文件，永远做不到把答案收回来。

至于转写全文和流程的逐步经过，记录里的链接会带你回到 WaveKat 的通话页面，那里有[双轨播放器和按说话人标注的转写](/zh/blog/share-a-call-recording/)。

## 连接一次——不需要 API 密钥，也不需要额外配置

连接只是账户页面上的一次点击：你会来到 HubSpot 自己的授权页面，同意后就回来了——连接完成。不需要注册开发者账号，不需要配置私有应用，不需要挑选权限范围，也没有任何要粘贴的令牌。在你点击之前，页面会明白地写出将要发送的内容，[隐私政策](/zh/privacy/#integrations)里也用同样的话写着同样的事。

断开连接同样干净：WaveKat 会请 HubSpot 吊销访问权限，并抹掉存储的凭据。已经写进你 HubSpot 的通话记录会留在原地——那是你 CRM 的历史，断开一个集成不等于删除你的过去。

## 同步什么，由你决定

四个开关，每个连接单独设置：

| 开关 | 默认 | 作用 |
|---|---|---|
| 同步转写 | 开 | 把通话内容写进通话记录 |
| 创建联系人 | 开 | 号码无人匹配时，自动创建一个 HubSpot 联系人 |
| 同步删除 | 开 | 你在 WaveKat 里删除通话时，归档对应的 HubSpot 记录 |
| 用号码命名未知来电 | 关 | 运营商没有传来姓名时，用来电号码作为联系人姓名 |

最后一个默认关闭是有意的：空白的姓名才是准确的，第一位认出这个号码的同事会把名字永久补上。当你确实打开它时，号码会写进姓氏字段——绝不写进名字字段，因为 HubSpot 会把名字用于邮件个性化，而「你好，021 123 4567」不是任何人想发出去的邮件。

还有一句要诚实说的话，和[隐私政策](/zh/privacy/#integrations)里说的是同一句：与你通话的那个人，从未与我们达成过任何约定。把对方的号码、声音和话语记进你的 CRM，和录下这通电话本身是同一份责任——这些开关的存在，就是让你把同步的内容控制在你愿意承担的范围之内。

## 每通电话都告诉你它去了哪里

在 WaveKat 里打开任何一通电话，它都会告诉你这通电话有没有到达你的 CRM：已写入时显示 **In HubSpot** 徽章，在路上时显示等待状态，出了问题时会用 HubSpot 自己的原话告诉你原因。失败的同步会以退避间隔重试一整天；失去访问权限的连接会提示「重新连接」，而不是悄无声息地失败。不用猜管道是不是还在工作。

## 把通话记录进 HubSpot 的几种方式

把电话记录进 HubSpot 有好几条路，各自适合不同的情况：

| 方式 | 需要什么 | 保留你现有的电话服务商？ |
|---|---|---|
| 手动登记 | 每通电话后都有人去填写 | 是 |
| HubSpot 自带的通话功能 | 用 HubSpot 提供的号码、在 HubSpot 里打电话 | 否 |
| 云端外呼平台 | 把整套通话搬到该平台，按坐席付费 | 否 |
| Webhook 加自动化工具 | 一份第三方自动化套餐，外加一条要维护的管道 | 是 |
| WaveKat Voice 原生集成 | 点一下连接；通话仍走你自己的 SIP 线路 | 是 |

外呼平台在它们擅长的事上确实出色——批量外呼、短信、面向销售团队的通话辅导。它们的前提是你把通话搬过去。WaveKat Voice 押的是相反的方向：你继续用[你已经在用的电话服务商](/zh/voice/)，通话发生在你自己的电脑上，HubSpot 是你的通话去汇报的目的地——而不是它们栖身的系统。

## 免费与 Pro

原生 HubSpot 集成是一项 **Pro** 功能——与[用菜单和转接来分流来电](/zh/blog/answer-calls-with-a-call-flow/)属于同一档。在抢先体验期间，升级到 Pro 是免费的：在[你的 WaveKat 账户页面](https://platform.wavekat.com/profile)点一下，没有付款步骤，有效期一年。

免费账户依然有通向 CRM 的路：**Webhook**，它把每通电话的记录发送到你给定的任意 URL——测试期间免费。而原生集成是当你想要那些有状态的能力时才需要升级的东西：联系人匹配、去重的记录、录音播放，以及会同步过去的删除。

## 常见问题

### 如何用 WaveKat Voice 把通话自动记录到 HubSpot？

登录你的 WaveKat 账户并开启云同步，然后在「集成」页面点击「连接 HubSpot」，在 HubSpot 的授权页面上同意即可。此后你在 WaveKat Voice 里接听或拨出的每一通电话都会自动写入 HubSpot——每通电话都无需任何操作。

### WaveKat Voice 会自动创建 HubSpot 联系人吗？

会，只要「创建联系人」保持开启。WaveKat 按电话号码把每通电话匹配到 HubSpot 联系人；没有人匹配时，它会创建该联系人，让通话仍然落在具体的人名下。关闭后，未匹配的通话会被记录，但不关联联系人。

### 可以在 HubSpot 里直接播放通话录音吗？

可以。有录音的通话，其 HubSpot 记录可以在联系人时间线上用 HubSpot 自带的播放器播放。音频是在播放时向 WaveKat 实时获取的，而不是复制过去的——所以在 WaveKat 里删除通话是真正的删除，CRM 里不会留下散落的副本。

### 在 WaveKat 里删除通话后，HubSpot 那边会怎样？

「同步删除」开启时（默认如此），你在 WaveKat 里删除通话，对应的 HubSpot 记录会被归档，录音也随之无法播放。关闭它，即使通话已从 WaveKat 消失，你的 HubSpot 历史也会保留那条记录。

### 连接 HubSpot 需要 API 密钥吗？

不需要。连接就是经由 HubSpot 自己的授权页面的一次点击——没有要配置的私有应用，也没有要创建或粘贴的 API 密钥。如果你更想自建管道，Webhook 依然可用，会把每通电话发送到你指定的任意 URL。

### HubSpot 集成免费吗？

它是一项 Pro 功能。抢先体验期间 Pro 免费——在你的 WaveKat 账户页面点一下即可获得一年，没有付款步骤。免费账户仍可使用 Webhook，作为通往 CRM 的自助路线。

### 支持哪些平台？

WaveKat Voice 目前支持 Mac 和 Linux。HubSpot 集成在你的 WaveKat 账户里运行，两个平台上完全一样——它记录下的通话，在任何浏览器里打开 HubSpot 都能看到。
