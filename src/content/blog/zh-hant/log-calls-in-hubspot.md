WaveKat Voice 現在可以把通話自動記錄到 HubSpot。在你的 WaveKat 帳號裡連接一次 HubSpot，之後你接聽或撥出的每一通電話都會自動寫進你的 CRM——落在正確的聯絡人名下，帶著時間、方向、結果、時長、完整轉寫，還有一段不用離開 HubSpot 就能播放的錄音。不需要 API 金鑰，不需要中介軟體，不需要瀏覽器擴充功能，掛斷之後也沒有任何要記得去做的事。它今天已在[你的 WaveKat 帳號](https://platform.wavekat.com/integrations)上線，是一項 Pro 功能——而在搶先體驗期間，Pro 是免費的。

這仍然是我們在做的那件事的又一塊拼圖：[讓每一家小公司都擁有大公司的聲音](/zh-hant/blog/hello-world/)。大公司的 CRM 之所以記得每一通電話，是因為有人專門負責讓它記得。你的 CRM 也可以記得每一通電話——因為你本來就在用的那款[為每通電話錄音並轉寫](/zh-hant/voice/)的電話應用程式，會安靜地把它寫到你的客戶資料所在的地方。

## 每通電話結束後，HubSpot 裡會有什麼

通話結束時，WaveKat 會按電話號碼在你的 HubSpot 聯絡人裡查找對方，並把一筆通話記錄寫到對方的時間軸上：

| HubSpot 裡的內容 | 具體是什麼 |
|---|---|
| 聯絡人 | 按電話號碼比對；沒有相符時可以自動建立 |
| 時間與方向 | 通話發生的時間，來電還是撥出 |
| 結果與時長 | 已接聽、未接或失敗——以及通話持續了多久 |
| 標題 | 一行摘要，例如「來電 · 已接聽 · 非營業時間」 |
| 轉寫 | 完整的對話內容，除非你關閉轉寫同步 |
| 錄音 | 通話有錄音時，可直接在 HubSpot 自帶的播放器裡播放 |
| 連結 | 指回 WaveKat 裡的這通電話，那裡有波形圖和流程的每一步 |

這筆記錄看起來就像一位盡責的同事手動登記的通話——只不過它涵蓋每一通電話、逐字逐句，而且是在你去倒咖啡的時候完成的。同一個人打來兩次，或者一次同步發生重試，同一通電話也絕不會被記兩遍：WaveKat 記得哪筆 HubSpot 記錄屬於哪通電話，會去更新它，而不是再造一筆孿生記錄。

## 在 HubSpot 裡直接播放錄音

錄音並不會被複製進 HubSpot——實際發生的事更好。通話記錄裡帶著 HubSpot 所需的資訊，讓它在*有人按下播放的那一刻*來向 WaveKat 詢問音訊，WaveKat 當場應答。這在實際使用中意味著：

- **播放就發生在聯絡人時間軸上。** 同事在 HubSpot 裡回顧一筆交易時按下播放就能聽到通話——不用切換應用程式，不用轉寄檔案。
- **刪除一通電話，就是真的刪除。** 錄音在 WaveKat 裡被刪除後，HubSpot 那邊沒有任何殘留副本可以比它活得更久。下一次按播放什麼也找不到，因為確實什麼也沒有了。
- **存取權始終在你手裡。** 每一次播放都是一次由 WaveKat 應答的請求，也就可以被拒絕——比如整合已中斷、通話已刪除。一份被複製走的音訊檔，永遠做不到把答案收回來。

至於完整轉寫和流程的逐步經過，記錄裡的連結會帶你回到 WaveKat 的通話頁面，那裡有[雙軌播放器和按說話者標註的轉寫](/zh-hant/blog/share-a-call-recording/)。

## 連接一次——不需要 API 金鑰，也不需要額外設定

連接只是帳號頁面上的一次點按：你會來到 HubSpot 自己的授權頁面，同意後就回來了——連接完成。不需要註冊開發者帳號，不需要設定私有應用程式，不需要挑選權限範圍，也沒有任何要貼上的權杖。在你點按之前，頁面會明白地寫出將要傳送的內容，[隱私權政策](/zh-hant/privacy/#integrations)裡也把同一份清單寫得明明白白。

![網頁版 WaveKat 的「整合」頁面——HubSpot 在可用整合裡標著「已連接」，下方是已連接的帳號，顯示「同步中」和幾分鐘前的最近一次同步。](/screenshots/integrations-hubspot/zh-Hant.webp#shadow)

中斷連接同樣乾淨：WaveKat 會請 HubSpot 撤銷存取權限，並抹掉儲存的憑證。已經寫進你 HubSpot 的通話記錄會留在原地——那是你 CRM 的歷史，中斷一個整合不等於刪除你的過去。

## 同步什麼，由你決定

四個開關，每個連接單獨設定：

| 開關 | 預設 | 作用 |
|---|---|---|
| 包含逐字稿 | 開 | 把通話內容寫進通話記錄 |
| 建立缺少的聯絡人 | 開 | 來電號碼比對不到聯絡人時，新建一個 |
| 同步刪除 | 開 | 你在 WaveKat 裡刪除通話時，也從 HubSpot 中移除 |
| 用號碼作為未知來電者的姓名 | 關 | 電信業者沒有傳來姓名時，用來電號碼作為聯絡人姓名 |

![網頁版的連接設定面板——哪些通話事件會送到 HubSpot，以及「建立缺少的聯絡人」「用號碼作為未知來電者的姓名」「包含逐字稿」「同步刪除」四個開關。](/screenshots/integrations-hubspot-options/zh-Hant.webp#shadow)

最後一個預設關閉是有意的：空白的姓名才是準確的，第一位認出這個號碼的同事會把名字永久補上。當你確實打開它時，號碼會寫進姓氏欄位——絕不寫進名字欄位，因為 HubSpot 會把名字用於郵件個人化，而「你好，021 123 4567」不是任何人想寄出去的信。

還有一句要誠實說的話，和[隱私權政策](/zh-hant/privacy/#integrations)裡說的是同一句：與你通話的那個人，從未與我們達成過任何約定。把對方的號碼、聲音和話語記進你的 CRM，和錄下這通電話本身是同一份責任——這些開關的存在，就是讓你把同步的內容控制在你願意承擔的範圍之內。

## 每通電話都告訴你它去了哪裡

在 WaveKat 裡打開任何一通電話，它都會告訴你這通電話有沒有到達你的 CRM：已寫入時顯示**「已在 HubSpot 中」**徽章，在路上時顯示等待狀態，出了問題時會用 HubSpot 自己的原話告訴你原因。失敗的同步會以退避間隔重試一整天；失去存取權限的連接會提示「重新連接」，而不是悄無聲息地失敗。不用猜管線是不是還在運作。

## 把通話記錄進 HubSpot 的幾種方式

把電話記錄進 HubSpot 有好幾條路，各自適合不同的情況：

| 方式 | 需要什麼 | 保留你現有的電信業者？ |
|---|---|---|
| 手動登記 | 每通電話後都有人去填寫 | 是 |
| HubSpot 自帶的通話功能 | 用 HubSpot 提供的號碼、在 HubSpot 裡打電話 | 否 |
| 雲端外撥平台 | 把整套通話搬到該平台，按坐席付費 | 否 |
| Webhook 加自動化工具 | 一份第三方自動化方案，外加一條要維護的管線 | 是 |
| WaveKat Voice 原生整合 | 點一下連接；通話仍走你自己的 SIP 線路 | 是 |

外撥平台在它們擅長的事上確實出色——批量外撥、簡訊、面向業務團隊的通話輔導。它們的前提是你把通話搬過去。WaveKat Voice 押的是相反的方向：你繼續用[你已經在用的電信業者](/zh-hant/voice/)，通話發生在你自己的電腦上，HubSpot 是你的通話去回報的目的地——而不是它們棲身的系統。

## 免費與 Pro

原生 HubSpot 整合是一項 **Pro** 功能——與[用選單和轉接來分流來電](/zh-hant/blog/answer-calls-with-a-call-flow/)屬於同一檔。在搶先體驗期間，升級到 Pro 是免費的：在[你的 WaveKat 帳號頁面](https://platform.wavekat.com/profile)點一下，沒有付款步驟，有效期一年。

免費帳號依然有通往 CRM 的路：**Webhook**，它把每通電話的記錄傳送到你給定的任意 URL——測試期間免費。而原生整合是當你想要那些有狀態的能力時才需要升級的東西：聯絡人比對、去重的記錄、錄音播放，以及會同步過去的刪除。

## 常見問題

### 如何用 WaveKat Voice 把通話自動記錄到 HubSpot？

登入你的 WaveKat 帳號並開啟雲端同步，然後在「整合」頁面點按「連接 HubSpot」，在 HubSpot 的授權頁面上同意即可。此後你在 WaveKat Voice 裡接聽或撥出的每一通電話都會自動寫入 HubSpot——每通電話都無需任何操作。

### WaveKat Voice 會自動建立 HubSpot 聯絡人嗎？

會，只要「建立缺少的聯絡人」保持開啟。WaveKat 按電話號碼把每通電話比對到 HubSpot 聯絡人；沒有人相符時，它會建立該聯絡人，讓通話仍然落在具體的人名下。關閉後，未比對到的通話會被記錄，但不關聯聯絡人。

### 可以在 HubSpot 裡直接播放通話錄音嗎？

可以。有錄音的通話，其 HubSpot 記錄可以在聯絡人時間軸上用 HubSpot 自帶的播放器播放。音訊是在播放時向 WaveKat 即時取得的，而不是複製過去的——所以在 WaveKat 裡刪除通話是真正的刪除，CRM 裡不會留下散落的副本。

### 在 WaveKat 裡刪除通話後，HubSpot 那邊會怎樣？

「同步刪除」開啟時（預設如此），你在 WaveKat 裡刪除通話，對應的 HubSpot 記錄會被封存，錄音也隨之無法播放。關閉它，即使通話已從 WaveKat 消失，你的 HubSpot 歷史也會保留那筆記錄。

### 連接 HubSpot 需要 API 金鑰嗎？

不需要。連接就是經由 HubSpot 自己的授權頁面的一次點按——沒有要設定的私有應用程式，也沒有要建立或貼上的 API 金鑰。如果你更想自建管線，Webhook 依然可用，會把每通電話傳送到你指定的任意 URL。

### HubSpot 整合免費嗎？

它是一項 Pro 功能。搶先體驗期間 Pro 免費——在你的 WaveKat 帳號頁面點一下即可獲得一年，沒有付款步驟。免費帳號仍可使用 Webhook，作為通往 CRM 的自助路線。

### 支援哪些平台？

WaveKat Voice 目前支援 Mac 和 Linux。HubSpot 整合在你的 WaveKat 帳號裡運行，兩個平台上完全一樣——它記錄下的通話，在任何瀏覽器裡打開 HubSpot 都能看到。
